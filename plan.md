#### 2.2.1 Fusion (RRF и DBSF)

1. Для каждого запроса из `queries`:
    - Получить dense embedding запроса
    - Получить sparse embedding запроса
    - Выполнить поиск 10 ближайших соседей с помощью dense и sparse моделей
    - Применить RRF (Reciprocal Rank Fusion) с разными значениями k
    - Применить DBSF (Dense Before Sparse Fusion)
2. Вычислить MRR для каждого метода:
   ```python
   def calculate_mrr(search_results, relevant_docs):
       reciprocal_ranks = []
       for query_id, results in search_results.items():
           relevant_ids = relevant_docs.get(query_id, [])
           for rank, result in enumerate(results, 1):
               if result['_id'] in relevant_ids:
                   reciprocal_ranks.append(1/rank)
                   break
           else:
               reciprocal_ranks.append(0)
       return sum(reciprocal_ranks) / len(reciprocal_ranks)
   ```
3. Зафиксировать полученные MRR значения в комментариях (ожидаемый диапазон: 0.5-0.65)
